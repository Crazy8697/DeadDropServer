The first public release of Dead Drop Server, the optional sync server for Dead Drop Finance.

- Keeps the Android app and the Windows program in step, on your own hardware, in Docker.
- The image: `ghcr.io/crazy8697/deaddrop-server:0.5.0` (also `latest`). Setup steps are in the README.
- The server holds a readable copy of your budget so your devices can share it. The connection between your devices
  and the server is encrypted, and the server backs itself up, encrypted, once a day.
- One account per server, made once with a one-time setup code; you choose which devices get in and can remove one
  at any time.
- No password reset: any logged-in device can set a new password.
