Restore while logged in.

- Two new operations let a device that restored a backup make it the server's budget: `master.check` (the device holds the edit lock and the server can write its own backup) and `master.replace`.
- Before the server replaces its budget, it writes and checks its own encrypted backup of the current one. If that backup fails, nothing is changed and the device is told why.
- The replace is one step. Every other device finds out at its next sync and takes the restored budget, after saving its own.
- Needs Dead Drop Finance 1.7.2 (Android app) or 0.12.2 (Windows program) to use it. Older ones keep working; they just can't restore while logged in.
- The image is `ghcr.io/crazy8697/deaddrop-server:0.5.1` (also `latest`). Nothing changes in how you run it.
